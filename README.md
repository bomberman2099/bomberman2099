## Selected Projects

### Octina
A workforce attendance and HR management platform built with Django.  
It includes attendance flow, location verification, shift handling, payroll calculation, warnings, vacation workflows, and Excel reporting.

### WaIT
A queue management backend system built with Django REST Framework.  
It handles centers, visitors, queue progression, public token-based status access, SMS notifications, and rating submission after service completion.

### Multi-Brand Service Website
A configuration-driven Django project for generating brand-specific service websites from a shared codebase.  
It uses reusable templates, dynamic content, and brand-specific SEO and theming.
